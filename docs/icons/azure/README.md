# Azure architecture icons

These SVG files are unmodified copies from Microsoft's official Azure architecture icon set (version V25), renamed for readability. They are used only in this project's architecture diagrams.

- Source: [Azure icons, Azure Architecture Center](https://learn.microsoft.com/en-us/azure/architecture/icons/)
- Terms: "Microsoft permits the use of these icons in architectural diagrams, training materials, or documentation. You can copy, distribute, and display the icons only for the permitted use unless granted explicit permission by Microsoft. Microsoft reserves all other rights."

`scripts/render_technical_architecture.py` embeds these icons in `docs/technical-architecture.svg`.
